# Whisper STT (תמלול קול)

שירות תמלול-קול עצמאי (self-hosted), מבוסס על מנוע Whisper, עם REST API פשוט. נבנה כדי לשמש
את תוסף "Smart Home Jewish" לשליטה-קולית — אבל ניתן לקרוא לו מכל מקום ברשת הבית.

## הגדרות

- **asr_model**: גודל-המודל. `tiny`/`base` מהירים אבל פחות-מדויקים בעברית; `small` הוא
  ברירת-המחדל — איזון טוב בין דיוק למהירות על חומרה רגילה; `medium`/`large-v2`/`large-v3`
  מדויקים משמעותית יותר אבל איטיים-בהרבה בלי GPU.
- **asr_engine**: `faster_whisper` (ברירת-מחדל) — הרבה יותר מהיר על CPU מ-`openai_whisper`
  הרגיל, באותה-דיוק בערך.

בכל שינוי צריך Stop→Start לתוסף הזה (לא רק שמירה) כדי שהמודל-החדש יטען.

## הפעלה ראשונה

בעליה-הראשונה (ובכל שינוי-מודל) ה-add-on מוריד את קובצי-המודל מהאינטרנט — זה יכול לקחת כמה
דקות, בהתאם לגודל-המודל ולמהירות-האינטרנט. אפשר לעקוב בלוג של ה-add-on.

## שימוש (REST API)

נקודת-הקצה העיקרית:

```
POST http://<כתובת-ה-HA>:9000/asr?task=transcribe&language=he&output=json
Content-Type: multipart/form-data
שדה: audio_file = <קובץ-השמע>
```

דוגמה עם curl (קובץ WAV מקומי):

```bash
curl -s -X POST \
  "http://homeassistant.local:9000/asr?task=transcribe&language=he&output=json" \
  -F "audio_file=@recording.wav;type=audio/wav"
```

תגובה (JSON): `{"text": "הטקסט המתומלל כאן"}`

ניתן גם לבקר ב-`http://<כתובת-ה-HA>:9000/docs` לתיעוד Swagger אינטראקטיבי מלא (כל הפרמטרים,
ניסוי-ישיר מהדפדפן).

## הערות

- מודל `small` ומעלה תומך בעברית טוב למדי לפקודות-קצרות (כמו "תדליק את המזגן בסלון לחצי שעה").
- אין צורך להגדיר `language=he` במפורש — Whisper יכול גם לזהות-שפה אוטומטית — אבל קביעתו
  במפורש משפרת-דיוק ומקצרת-זמן-עיבוד, ומומלצת כש-כל השיחות בעברית (המקרה שלנו).
